# howdy — Onboarding

Run at session start to load working context for the Matter Library.

## Steps

1. Read `.ai/context.md` (identity, exists-vs-planned, active phase).
2. Read `.ai/conventions.md` (rules; note **Don't Delete Spec Functionality**).
3. Read `.ai/plan/build_plan.md` (find the Active phase).
4. Open the active phase doc named in build_plan.
5. Skim `Readme.md` for the current design (much is `(planned)` — that's expected).
6. Confirm working directory and what's in scope before acting.

## Output

Give a one-paragraph status: active phase, what's in scope, what's next. Note that this repo
is in research/define phase — design runs ahead of disk. Ask before starting work.
