# Phase17 — Character Materials, Their Own Library

**Status:** SEEDED (2026-10-14). **Numbered Phase17 by the lead the same day:** *"Lets make these the next phases (Before the scaled grid)"*. A pointer-shell written by `/research` on the lead's word: *"yes record it and seed all three"*. **Starting discovery is a deliberate gate, the lead's call, never a slide.** It is third of three, after *Matter, Character and HDRI* ([`Phase15_MatterCharacterHdri.md`](Phase15_MatterCharacterHdri.md)) and *Every Entry Says What It Is* ([`Phase16_EveryEntrySaysWhatItIs.md`](Phase16_EveryEntrySaysWhatItIs.md)) (RD-DS-5).

## Outcome

**A contributor can craft a set of teeth, a skin or an eye that fits the character's own part mesh, keep their name on it, and see it pictured on that part: teeth on teeth, skin on half a face and hands, an eye on an eyeball.**

## Why this is a phase of its own

The lead: *"the characters dots do not use "matter" level materials very well.. they look like totall shit to be frank... We need to think about character materials differnly so they need to officiallbe handled in a another very clear taxonomy/ontology that people can participate in. the need to be able to craft a set of teeth that will uvmap to the predefined teeth mesh we picked, and that should keep their name so people can realize how great a teeth a particular contributor is"* (RD-DS-4). Character materials stop being tiling Matter materials put on a body. Each becomes a set of maps authored to one part mesh's UVs.

## Scope — as known at research (2026-10-14)

The authority until this phase writes its specs: [`261014_R_DownstreamPicture.md`](../Research/261014_R_DownstreamPicture.md) §Resolved (RD-DS-4) and F-DS-13.

- **Each part names the mesh it fits, versioned.** Today there is one approved human mesh (MakeHuman hm08 on the Manny skeleton, Glossary *Approved human mesh*), already split into one mesh per substance by the rig (`PlatformDependencies.md` P15).
- **A contribution keeps its contributor's name** where people see it: in the name grammar, or in the displayed name that *Every Entry Says What It Is* carries. Discovery settles which.
- **One picture rig per part, on that part's mesh,** never the rig's cubes. This takes over the Character subjects from *Thumbnails* (RD-MP-3).
- **Its first instances are already seeded:** *Skin Maps* ([`Future/PhaseTBD_SkinMaps.md`](Future/PhaseTBD_SkinMaps.md)) and *Skin Maps Beyond Colour* ([`Future/PhaseTBD_SkinMapsBeyondColour.md`](Future/PhaseTBD_SkinMapsBeyondColour.md)) already author maps per approved mesh version (RD-SKM-1). Whether they run inside this phase or ahead of it is the lead's call when it is opened.
- **Species beyond humanoid** (canine, equine) are allowed for by the taxonomy (*Matter, Character and HDRI*), not built here.
