# matterlib-0.1.0 — texture provenance record

Auditable pixel provenance for every shipped texture in the `matterlib-0.1.0` release
(Phase 60, RD-Provenance policy). **Every entry is clean-provenance** — the audit (Phase 60.5)
found no clouded / unlicensed AI-bootstrap pixels: the earlier ComfyUI-SDXL bootstrap concern
(Discovery 7.2) does not apply to the shipped set. Two clean classes:

- **procedural** — deterministic fixed-seed value-noise, generated by a committed script with no
  network and no third-party input; byte-stable for a given seed/size (`gen_*.py`). IMRSV-owned,
  released CC0-1.0. The generator script *is* the reproducible evidence.
- **ambientCG (CC0-1.0)** — sourced from [ambientCG](https://ambientcg.com), a CC0 (public-domain)
  PBR-texture library. Introduced in commit `7198abf` ("Phase 53.5+53.6 (textured) — author 3
  textured proof articles (ambientCG CC0)"). No attribution or license obligation; free for
  commercial redistribution.

This file is the `evidence` artifact referenced by the ambientCG entries' `provenance.evidence`
in `library/releases/matterlib-0.1.0.lock.yaml`; procedural entries point `evidence` directly at
their generator script.
